# IEA BioGRAM 1.2

- `BioGRAM_1-2.xlsx`: the file as downloaded from the IEA page below (updated 21/09/2026).
- `biogram_1_2_paises.csv`: sheet `BioGRAM-1.2`, one row per country plus `World`. Biomethane
  potential in bcm per year (the methodology note defines 1 Nm³ of methane as 36 MJ). National
  values only; there is no sub-national breakdown in the file.
- `biogram_1_2_definicoes.csv`: sheet `Definitions`, what each feedstock group contains.

Forestry residues are not included. The methodology note (Biogases Geospatial Resource Assessment
Model, Documentation, July 2026) is linked from the same page.

Source: IEA (2026), Interactive map of global biogas and biomethane potential,
https://www.iea.org/data-and-statistics/data-tools/interactive-map-of-global-biogas-and-biomethane-potential.
