## Semantics that are easy to break

- **Biogás ≠ metano.** BMP is NmL CH₄/gVS, so the chain yields *methane*. Raw
  biogas = CH₄ ÷ ch4_pct (52–72%, median 57%). biometano/metano = 0.97
  (upgrading recovery); biometano/biogás ≈ 0.53 (volumetric yield). **Bioenergia
  must read the CH₄ band** — 9.97 kWh/m³ is methane's calorific value.
- **Crop columns hold RESIDUE**, uniformly. RPR lives in `feedstocks.yaml`, gross;
  collectability stays in `fde`. Sugarcane additionally multiplies by
  `mill_delivery_fraction` (0.85) because bagaço is an *industrial* residue and
  PAM measures cane *produced*, not *crushed*.
- **Coverage is recorded, not inferred.** Absence from
  `municipality_biomass_provenance` means `no_data`. A measured 0 and a null are
  different facts and must display differently — "0 t/ano" vs "Sem dados".
- **Urban prefers measured**: SNIS CO111 collected tonnage × organic fraction
  where reported (4,140 municipalities), population model elsewhere.

   It sums legacy `*_biogas_m3_year`/`population` columns, populated for 645
   municipalities. `total_population` returns 46M, not 203M. Most visible

   `overview` once. Then vector tiles — geometry is now the majority of what is
   left in the payload.

   and runs; 38 unmatched rows are wrong-state attributions in MapBiomas, not

## VM operational notes

`/` is 15 GB and tight; **`/data` has ~72 GB free** and now holds
`municipalities`, `municipality_timeseries`, `audit_log` (tablespace
`pilar_data`), plus `/data/pilar2b/raw/` and `/data/pilar2b/backups/`.

- **Always `git log --oneline -1` after `git pull`, before restarting.** Two false
  deploys today came from restarting unchanged code.
- **Never `sudo` inside a user-owned git repo** — `sudo git gc` left `.git`
  root-owned and silently blocked pulls.
- `ALTER TABLE ... SET TABLESPACE` does **not** move indexes.
- **`/dev/sda4` is a phantom duplicate of sda3** (same sectors, same UUID).
  Never mount, format or fsck it.
