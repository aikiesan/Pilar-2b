# August 2026 playbook — National DB spine + core national sources

_Prerequisite: July exit criteria met (migration 021 applied, contract proven
on ANEEL SIGA)._

## Week 1 — national municipality spine

1. Download the IBGE 2024 municipal mesh (malha municipal digital,
   `BR_Municipios_2024` shapefile/geopackage — geobr or the IBGE FTP).
   Record in METADATA.json (`ibge_malha_2024`).
2. Generate two simplification levels with ogr2ogr (targets: full ≈ 1:250k
   source; simplified for overview zooms):
   ```bash
   ogr2ogr -f GPKG br_mun_full.gpkg BR_Municipios_2024.shp -t_srs EPSG:4326
   ogr2ogr -f GPKG br_mun_simple.gpkg br_mun_full.gpkg -simplify 0.005
   ```
3. Extend `scripts/import_shapefile_geometry.py` (or a new
   `ingest/sources/ibge_malha/`) to upsert all 5,570 rows into
   `municipalities` (name, ibge_code, uf, geometry, centroid, area_km2),
   `data_confidence='provisional'` for non-SP rows.
4. Verify:
   ```sql
   SELECT count(*) FROM municipalities;                       -- 5570
   SELECT uf, count(*) FROM municipalities GROUP BY uf
     EXCEPT SELECT uf, municipality_count FROM states;        -- 0 rows
   SELECT count(*) FROM municipalities WHERE geometry IS NULL; -- 0
   ```
5. **SP regression**: re-run the SP headline numbers; they must be unchanged
   (the spine import touches no biogas columns). Regression gate report.

## Week 2 — seeded national test DB + re-harden E2E

6. Build a deterministic seed (`tests/fixtures/national_seed.sql`): all 5,570
   municipalities with geometry + synthetic-but-plausible biogas values, tiny
   plant/pipeline sets. Source it in CI's PostGIS service (like
   `tests/ogc/fixtures/seed_min.sql` does for OGC).
7. Point the E2E workflow at a locally seeded backend instead of the
   production API (this was the documented re-hardening condition in
   `ci.yml`): start FastAPI against the CI DB, set
   `NEXT_PUBLIC_API_URL=http://localhost:8000`.
8. Run the E2E suite 3× green locally, then remove `continue-on-error` from
   the E2E step. CI gates: 8 of 9 hard.

## Weeks 3–4 — three national ingests (one PR each, contract steps 0–5)

9. **IBGE PAM 2023 national** (`ingest/sources/ibge_pam/`): SIDRA tabela 5457
   via API (`https://apisidra.ibge.gov.br/values/t/5457/...`) or CSV export.
   Key validation: state totals vs SIDRA's own aggregates (±0.5%); coverage
   gate national (allowlist for municipalities with suppressed values, "X" in
   SIDRA — document them).
10. **IBGE PPM 2023 livestock** (`ingest/sources/ibge_ppm/`): herd counts
    (cattle/swine/poultry, SIDRA tabela 3939). Cross-source gate vs Censo
    Agro 2017 at state level (r² > 0.9 expected; investigate outliers).
11. **SNIS** (`ingest/sources/snis/`): municipal solid waste + sewage.
    Range gate: per-capita waste 0.5–1.5 kg/hab/day vs IBGE Censo 2022
    population (cross-source). Missing-data map documented (SNIS is
    self-reported; expect real gaps → allowlist with counts per UF).
12. After each promote: recompute residues for covered states with existing
    SP factors, `data_confidence='provisional'`, regression gate on SP.

## Stretch (only if weeks 1–2 finished early)

13. RGint national choropleth behind a feature flag (133 polygons — fine on
    Leaflet): extend `/intermediate-regions/geojson` to serve all 133 with
    the new national aggregates.
