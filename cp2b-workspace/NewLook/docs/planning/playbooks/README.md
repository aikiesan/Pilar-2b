# Month playbooks — Jul→Dec 2026

One file per month, each a self-contained checklist you can execute top to
bottom. They expand `BRAZIL_EXPANSION_ROADMAP.md` §6 into concrete steps with
commands, file paths and verification queries. Rules of engagement:

- Work top to bottom; every ~2 weeks the platform must be in a releasable state.
- Every ingest follows `docs/data/INGESTION_GUIDE.md` — one source per PR.
- At month end, fill your row in the roadmap's **progress indicators** table
  and carry unfinished items forward *explicitly* (edit next month's file).
- If a month overruns, cut scope by dropping P3 sources (RAIS, SICONFI, ANA)
  — never by skipping validation gates.
