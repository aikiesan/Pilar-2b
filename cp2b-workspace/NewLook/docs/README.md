# PILAR-2b Documentation Repository

Welcome to the documentation repository of **PILAR-2b** (*Plataforma Inteligente de Localização e Aproveitamento de Resíduos para Biogás e Bioprodutos*).

All documentation files are organized into domain-specific subdirectories for easy maintenance and navigation:

- 📖 **[DOCUMENTATION_INDEX.md](DOCUMENTATION_INDEX.md)** — Master index listing all ~50 documentation files, descriptions, and direct links.

---

## Directory Overview

| Directory | Content Description |
|---|---|
| 📂 **[`api/`](api/)** | OpenAPI & FastAPI REST endpoint specifications and request schemas |
| 📂 **[`architecture/`](architecture/)** | Platform overview, technology routes, maps integration, and performance optimizations |
| 📂 **[`auditorias/`](auditorias/)** | Audit logs, handoffs, and canonical consistency campaigns |
| 📂 **[`compliance/`](compliance/)** | Data provenance, LGPD compliance, DPIA/RIPD, and ROPA records |
| 📂 **[`data/`](data/)** | FDE methodology, feedstock factors, IBGE matrices, ingestion manuals, and [`datasets/`](data/datasets/) |
| 📂 **[`deployment/`](deployment/)** | Docker setup, Unicamp VM update guides, PostGIS setup, and production checklists |
| 📂 **[`manuscrito/`](manuscrito/)** | Scientific journal manuscript drafts and conference papers (FOSS4G) |
| 📂 **[`planning/`](planning/)** | National expansion roadmaps, playbooks, and improvement backlogs |
| 📂 **[`qa/`](qa/)** | Testing strategies, coverage status, WCAG accessibility, and QA guides |
| 📂 **[`security/`](security/)** | Security policy, audit reports, CSRF analysis, and database audit logging |
| 📂 **[`sql/`](sql/)** | SQL migration, seeding, and database fix scripts |
