# 🇧🇷 Brazil Intermediary Regions - Optimized Shapefiles

This directory contains optimized geographic and distance data for Brazil's 133 intermediary regions.

- ⚠️ **br_intermediary_regions.geojson** (1.19 MB)
  - Optimized GeoJSON for web display
  - 133 regions with simplified geometries
  - 98.8% reduction from original
  - Use in frontend React Leaflet maps

- ⚠️ **br_intermediary_regions.parquet** (0.65 MB)
  - Compressed GeoParquet for backend processing

## 📊 Data Specifications

### Coverage
- **Regions**: 133 intermediary regions (Regiões Intermediárias)
- **States**: All 27 Brazilian states
- **Source**: IBGE - Divisão Regional do Brasil 2017

### Coordinate System
- **Input CRS**: EPSG:4674 (SIRGAS 2000)
- **Output CRS**: EPSG:4326 (WGS84)
- **Reason**: Web mapping compatibility

### Geometry Simplification
- **Algorithm**: Douglas-Peucker
- **Tolerance**: 0.01 degrees (~1 km)
- **Reduction**: 98.8% (3,426,917 → 40,867 coordinates)
- **Topology**: Preserved (no invalid geometries)

### Distance Calculations
- **Formula**: Haversine (great-circle distance)
- **Pairs**: 133 × 133 = 17,689
- **Range**: 63.89 km to 4,021.29 km
- **Mean**: 1,557.95 km
- **Median**: 1,492.40 km

### Backend (Python)
```python
import geopandas as gpd
import pandas as pd

# Load parquet (faster than GeoJSON)
regions = gpd.read_parquet('br_intermediary_regions.parquet')

# Load distances
distances = pd.read_csv('br_intermediary_regions_distances.csv')

# Query specific distance
distance_sp_to_rj = distances[
    (distances['origin_cd_rgint'] == '3501') &
    (distances['target_cd_rgint'] == '3301')
]['distance_km'].values[0]
```
